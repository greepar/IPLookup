API 使用示例

直接返回你的 IPv4 地址字符串，适合在脚本中快速获取公网 IP。
curl https://4.qwq.lu/
terminal 返回示例
203.0.113.42
直接返回你的 IPv6 地址字符串，适合在脚本中快速获取公网 IP。
curl https://6.qwq.lu/
terminal 返回示例
2001:db8:85a3::8a2e:370:7334
返回包含 IP、地理位置、ASN、User Agent 等完整信息的 JSON 对象。
curl https://4.qwq.lu/?detail
terminal 返回示例 (JSON)
